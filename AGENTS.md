# Caudal — agent guide

Gestor de gastos personales. Next.js 16 (App Router) + React 19 + TypeScript strict, Tailwind v4, shadcn/ui (radix-nova), Prisma 7 + Postgres. Full architecture: `docs/ARQUITECTURA.md`.

## Folder conventions (docs/ARQUITECTURA.md §1)

- `src/app/` — routes only. `(auth)/` for login, `(app)/` for authenticated routes sharing the shell, `api/v1/` Route Handlers consumed by TanStack Query. `layout.tsx` = fonts, ThemeProvider, providers, Toaster.
- `src/components/ui/` — shadcn-generated. Add with `npx shadcn@latest add <name> -y`; avoid hand-editing unless needed.
- `src/components/{shell,data-table,charts}/` — shared app components; `money.tsx`, `empty-state.tsx` at the root of `components/`.
- `src/features/<feature>/` — feature-scoped `components/`, `hooks/`, `schemas.ts` (zod shared by form and handler), `types.ts`.
- `src/server/` — the ONLY layer that talks to Prisma (`db.ts`). Business logic lives in `server/services/*.service.ts` and every query filters by a `userId` resolved from the session, never from the client.
- `src/lib/` — pure helpers (`format.ts`, `dates.ts`, `query-keys.ts`, `utils.ts` with `cn`).
- `src/generated/prisma/` — Prisma client output, gitignored; regenerated by `postinstall` / `npm run db:generate`.
- `tests/unit/` — Vitest unit tests (`*.test.ts[x]`, also allowed colocated under `src/`); `tests/e2e/` reserved.

## Commands

- `npm run typecheck` (tsc --noEmit) · `npm run lint` · `npm test` (vitest run; single file: `npx vitest run tests/unit/format.test.ts`)
- `npm run db:migrate` (prisma migrate dev) · `npm run db:seed` · `npm run db:generate`

## Conventions & gotchas

- `src/app/globals.css` holds the design tokens (§3). Do NOT let `shadcn init` / `shadcn add` overwrite it — `init` replaced the palette with neutral defaults; diff it after any shadcn command and restore if touched.
- Money: signed amounts (positive = inflow), `Decimal(19,4)` in DB; format with `formatMoney` (uses U+2212 minus). Numbers get the `num` utility (tabular-nums).
- Theme: `next-themes` with `attribute="class"`; `.dark` tokens live in globals.css. `<html>` has `suppressHydrationWarning`.
- Don't rely on Next's generated global types (`LayoutProps`, `PageProps`) — `tsc --noEmit` runs without `.next/types` on a clean checkout. Type props explicitly.
- UI text is Spanish (`lang="es"`).
- Never commit `.env`; `.env.example` documents `DATABASE_URL` / `DIRECT_URL`.
