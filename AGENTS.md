# Caudal — agent guide

Gestor de gastos personales. Next.js 16 (App Router) + React 19 + TypeScript strict, Tailwind v4, shadcn/ui (radix-nova), Prisma 7 + Postgres. Full architecture: `docs/ARQUITECTURA.md`.

## Folder conventions (docs/ARQUITECTURA.md §1)

- `src/app/` — routes only. `(auth)/` for login, `(app)/` for authenticated routes sharing the shell, `api/v1/` Route Handlers consumed by TanStack Query. `layout.tsx` = fonts, ThemeProvider, providers, Toaster.
- `src/components/ui/` — shadcn-generated. Add with `npx shadcn@latest add <name> -y`; avoid hand-editing unless needed.
- `src/components/{shell,data-table,charts}/` — shared app components; `money.tsx`, `empty-state.tsx` at the root of `components/`.
- `src/features/<feature>/` — feature-scoped `components/`, `hooks/`, `schemas.ts` (zod shared by form and handler), `types.ts`.
- `src/server/` — the ONLY layer that talks to Prisma (`db.ts`). Business logic lives in `server/services/*.service.ts` and every query filters by a `userId` resolved from the session, never from the client.
- `src/lib/` — pure helpers (`format.ts`, `dates.ts`, `query-keys.ts`, `utils.ts` with `cn`).
- `src/generated/prisma/` — Prisma client output, gitignored; regenerated by `postinstall` / `npm run db:generate`.
- `tests/unit/` — Vitest unit tests (`*.test.ts[x]`, also allowed colocated under `src/`); `tests/e2e/` reserved.

## Conventions & gotchas

- `src/app/globals.css` holds the design tokens (§3). Do NOT let `shadcn init` / `shadcn add` overwrite it — `init` replaced the palette with neutral defaults; diff it after any shadcn command and restore if touched.
- Money: signed amounts (positive = inflow), `Decimal(19,4)` in DB; format with `formatMoney` (uses U+2212 minus). Numbers get the `num` utility (tabular-nums).
- Theme: `next-themes` with `attribute="class"`; `.dark` tokens live in globals.css. `<html>` has `suppressHydrationWarning`.
- Don't rely on Next's generated global types (`LayoutProps`, `PageProps`) — `tsc --noEmit` runs without `.next/types` on a clean checkout. Type props explicitly.
- UI text is Spanish (`lang="es"`).
- Never commit `.env`; `.env.example` documents `DATABASE_URL` / `DIRECT_URL`.

## App shell (`src/components/shell/`, `src/app/(app)/layout.tsx`)

- Every authenticated page lives under `src/app/(app)/` and gets the sidebar + topbar from its layout; `/` redirects to `/dashboard`. Nav items are defined once in `components/shell/nav-items.ts` (add new sections there).
- The `(app)` layout calls `await connection()` (per-request data; never prerendered at build) and loads sidebar balances server-side.
- Active month is the URL param `?month=YYYY-MM` (absent = current month), owned by `MonthSwitcher` via nuqs; read it with `useQueryState("month", parseAsString)`. Sidebar links preserve it.
- Sidebar becomes a left `Sheet` below `md`; page content should stay single-column-safe at 375 px.
- Page titles: `<h1>` 15/22 semibold inside the page (the topbar has no h1). `PagePlaceholder` is only for sections not yet built.
- Dev gotcha: editing files with `sed -i` (replace-by-rename) on this OneDrive folder can leave the dev server's SSR bundle stale → bogus hydration mismatches. Edit in place (Edit tool) or restart `next dev`.

## Dashboard (`src/features/dashboard/`, `src/app/(app)/dashboard/page.tsx`)

- The page (RSC) prefetches with `getQueryClient()` + `dashboardQueryKey(filters)` calling `getDashboard()` directly, then renders `DashboardView` inside `HydrationBoundary`. Key/filter helpers live in `features/dashboard/query.ts` (no "use client"): functions exported from a "use client" module reach the server as client references and cannot be called there.
- `DashboardView` owns loading/error for the KPI strip and lays out the 12-col grid of widgets (`data-slot="cashflow-chart" | "financial-health" | "category-donut" | "budget-list" | "recent-transactions"`), each with `order-N lg:order-none lg:col-span-N` classes (mobile order: health, budgets, recent, charts).
- All amounts go through `<Money>` (`components/money.tsx`) or `formatMoney`, never raw — the API can return fractional values. Sparklines: `components/charts/sparkline.tsx` (SVG, `currentColor`, pass `text-income`/`text-expense`).
- The KPI strip is a grid only at `xl`; below it is a scroll-snap carousel (with the 256 px sidebar, 4 segments don't fit 7–8 digit COP amounts between 768 and 1280 px).
- Widgets wrap themselves in `WidgetCard` (`features/dashboard/components/widget-card.tsx`: hairline section, h2, `actions` slot, `data-slot`) and call `useDashboard()` themselves (React Query dedupes) to own loading (skeleton with the final shape) / empty (`components/empty-state.tsx`) / error (`WidgetError`) states. The grid passes only `className`.
- Chart data shaping is pure and tested in `features/dashboard/chart-data.ts` (`buildCashflowRows`, `groupCategorySlices`). Cashflow projection appears only in the monthly range while the month is in progress (`0 < daysElapsed < daysInMonth`): hatched + dashed-outline remaining segments stacked on the real bars, and the net line becomes a dashed series from the previous month's net to `projectedMonthEnd.net`.
- Recharts conventions (`components/charts/`): every color is a CSS token string (`var(--income)`, `var(--muted-foreground)`, `var(--border)`…) so `.dark` just works; SVG patterns go in a `<defs>` child of the chart with ids from `useId()` stripped of non `[A-Za-z0-9_-]`; tooltips use `ChartTooltip`/`ChartTooltipRow` (popover tokens, hairline, `num`); axes use `formatMoney(v, { compact: true })`; `isAnimationActive={!usePrefersReducedMotion()}` on series and `false` on Tooltip. No gradients.
- "Añadir movimiento" CTAs call `requestQuickAdd({ type? })` from `@/lib/quick-add`, which dispatches `window` event `caudal:quick-add` (`QUICK_ADD_EVENT`, detail `QuickAddDetail`). Quick Add (QA-001) must listen to it; until then the CTA has no visible effect.
- Budget bars and the pace marker (docs §3 "Elemento firma"): logic in `features/dashboard/budget-pace.ts` (`expectedPace` → daysElapsed/daysInMonth, 1 for past months, null for future = no marker; `budgetTone` normal/ahead/warning/over). `BudgetProgress` is a `role="progressbar"` (valuenow clamped to 100, valuetext = real %, aria-label includes the expected pace); fills are neutral ink → `bg-warning` (≥ alertThreshold) → `bg-expense` (≥ 100 %). Fixed vs variable uses neutral `bg-foreground/70` / `/20`, never income/expense colors.
- RecentTransactions (`data-slot="recent-transactions"`): `DashboardData.recent` already has ONE row per transfer (the origin leg, amount < 0, plus `transferGroupId` and `counterpartAccountName`); render it as "Origen → Destino", category "Transferencia", unsigned amount in `text-transfer`. Rows are per-row CSS grids, so every non-flexible column needs a fixed width (amount 8.5rem, actions 1.75rem) or columns won't line up across rows. Row actions and the edit Sheet come from `features/transactions` (see its AGENTS.md).
