## Codebase Patterns
- Next.js 16.4 / React 19.3 / Tailwind v4 via `@tailwindcss/turbopack` loader in next.config.ts (no postcss config). Read `node_modules/next/dist/docs/` before using unfamiliar Next APIs.
- shadcn style is `radix-nova` (radix-ui umbrella pkg, `cn` from the `cn` package in src/lib/utils.ts). Add components with `npx shadcn@latest add <name> -y < /dev/null`; ALWAYS diff src/app/globals.css afterwards — shadcn init overwrote the design tokens once.
- Type layout/page props explicitly; Next's global `LayoutProps`/`PageProps` only exist after `next dev/build` typegen, so `tsc --noEmit` fails on a clean checkout.
- Tests: Vitest + jsdom, files in `tests/unit/**/*.test.ts[x]` or colocated `src/**/*.test.ts[x]`; run one with `npx vitest run <path>`.
- `postinstall` runs `prisma generate` (client in src/generated/prisma, gitignored).
- Root layout already provides ThemeProvider (class), TooltipProvider and `<Toaster />` (sonner) — don't add them again in nested layouts.
- DB: import `db` from `@/server/db` (only in src/server); types/enums from `@/generated/prisma/client`. Hand-written SQL migrations: `prisma migrate dev --create-only --name x`, edit, then `prisma migrate dev`. See prisma/AGENTS.md.
- API: Route Handlers use `handler()` from `@/server/http` (session user + zod + error mapping); see src/server/AGENTS.md. Client data: query keys only from `queryKeys` in `@/lib/query-keys`; RSC prefetch with `getQueryClient()` from `@/lib/query-client` (same defaults as the browser, staleTime 60 s). Root layout provides NuqsAdapter + QueryProvider.
- Dashboard math: pure helpers in `src/server/services/dashboard.calc.ts` (ISO date strings, user-tz "today"); services only query + map. Read currency/locale/timezone from the user record, never hard-code.
- Money formatting: `formatMoney`/`formatPercent` from `@/lib/format` default to COP / es-CO; always pass the user's `currency` and `locale` (from SessionUser or the DTO) — the shell gets `locale` as a prop from the (app) layout. COP/CLP/JPY… format with 0 decimals; grouping is "always". Intl output uses NBSP between the currency symbol and the amount — normalize in tests.
- Transaction mutations from any UI: use `useTransactionActions()` / `use*Transaction` hooks + `TransactionRowActions` / `TransactionSheet` from `src/features/transactions/` (they invalidate dashboard/transactions/accounts and `router.refresh()` the server-rendered sidebar). Client fetch helper: `apiFetch` from `@/lib/api`.
- Demo data: `npm run db:seed` (idempotent, rerunnable). Demo user id = `DEMO_USER_ID` from `@/server/demo-user`. Deterministic randomness: `createRng(seed)` from `@/lib/prng`.
- List pages: URL filter state with nuqs parsers from `nuqs/server` in a client-safe `filters.ts` shared by the RSC page (createLoader + prefetchInfiniteQuery) and the client hooks; derive the query key from the same helper so hydration hits. Colors stored as `chart-N` tokens → `cssColor()` from `@/lib/color`. TanStack Table is v9 (`useTable`, `tableFeatures`), see src/features/transactions/AGENTS.md.
- Layout-level client components must not subscribe to queries a page prefetches (useAccounts/useCategories/useTags…): the early cache entry defers the page's HydrationBoundary hydration to an effect → React #418. Read with queryClient.getQueryData at event time. Global shortcuts: `useHotkeys` (src/hooks/use-hotkeys.ts); Quick Add / ⌘K via `requestQuickAdd()` / `requestCommandPalette()`.
- Accounts: `listAccountBalances(userId)` = active only (sidebar, Quick Add, filters); the /accounts page uses `{ includeArchived: true }` under `queryKeys.accounts.overview()`. Writes via `useCreateAccount`/`useUpdateAccount`/`useAccountActions` from src/features/accounts (see its AGENTS.md); type/currency are locked once an account has any transaction.
- Categories/rules: writes via hooks in src/features/categories/hooks (useInvalidateCategoryData). Categories are archived, never deleted; rule patterns stored via prepareRulePattern() (foldText / validated REGEX). `categories.list()` = active (forms), `categories.overview()` = settings. See src/features/categories/AGENTS.md.
