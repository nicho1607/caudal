# src/features/categories/ — categorías y reglas de categorización

- API: `GET /api/v1/categories` (activas, orden de árbol; `?include=archived` también archivadas), `POST` (201; con `parentId` el `kind` se hereda), `GET|PATCH /[id]`, `POST /[id]/archive` (se lleva las hijas activas con la MISMA marca de tiempo) y `/[id]/unarchive` (devuelve las hijas archivadas con esa marca; hija con padre archivado → 400). Nunca hay borrado. Reglas: `GET|POST /api/v1/categorization-rules`, `PATCH /[id]` (sin borrado: `isActive`). `GET /api/v1/payees` = comercios conocidos `{id,name}`.
- Services: `src/server/services/category.service.ts`, `categorization-rule.service.ts`, `payee.service.ts`; reglas puras en `category.logic.ts` (`resolveCategoryPlacement`: dos niveles, padre del mismo tipo, tipo bloqueado si `inUse` = movimientos incl. borrados / presupuestos / recurrentes, o si tiene hijas; `prepareRulePattern`: REGEX validado con `regexError()` de schemas.ts → 400 en español, el resto `foldText()`; `assertRulePatchAllowed`: SYSTEM sólo `isActive`). Nombres únicos entre hermanas sin tildes/mayúsculas → 409.
- DTOs (types.ts): `CategoryDTO` es superset de `CategoryOptionDTO` (nature, sortOrder, archivedAt, inUse) — los selects existentes siguen funcionando. `CategorizationRuleDTO` incluye `category` con `archived`.
- Query keys: `categories.list()` (activas: formularios), `categories.overview()` (ajustes, prefetch RSC), `categorize.rules()` (bajo `categorize` para que invalidar `categorize.all` limpie también las sugerencias). Mutaciones → `useInvalidateCategoryData()` (categories + categorize + dashboard/transactions/accounts + router.refresh()).
- Las reglas/payees que apuntan a categorías archivadas se ignoran al sugerir (categorization.service loadMatchData).
- Pure UI helpers en `form.ts` (árbol activo/archivado, payloads con sólo cambios, `testRule()` = la "prueba" en vivo con el `ruleMatches` real — categorization.match.ts no tiene deps de servidor, se puede importar en cliente). Iconos: catálogo cerrado en `components/category-icon.tsx` (nombres Lucide kebab-case; desconocido → Tag). Tests: tests/unit/category-logic.test.ts (puros) y category-service.test.ts (BD real, usuarios desechables).
